# AlphaGrab.app

**AlphaGrab.app** is a premium, high-demand sports ticket marketplace designed to help fans secure specific seats for the most sought-after matches in the Premier League, Champions League, and World Cup events.

## 🚀 Features

*   **Live Pricing Engine**: Real-time simulated price fluctuations based on demand.
*   **Global Coverage**: Dedicated sections for UK & England, Europe, and World events.
*   **Premium Experience**: A sleek, glassmorphism-inspired interface designed for speed and exclusivity.
*   **Instant Filtering**: Sort by popularity, price, or date to find the perfect match.

## 🛠️ Technology

Built with a focus on performance and modern design:
*   **HTML5 & CSS3**: Custom responsive layout with advanced animations.
*   **Vanilla JavaScript**: Lightweight and fast client-side logic.
*   **Font Awesome & Google Fonts**: For a polished, professional look.

## 📦 How to Use

### Option A: Run with Vite (recommended for auth)

1.  Clone or download the repository.
2.  Install dependencies: `npm install`.
3.  Create a `.env.local` file with:
	- `VITE_SUPABASE_URL=...`
	- `VITE_SUPABASE_ANON_KEY=...`
4.  Start the dev server: `npm run dev`.
5.  Open the local URL shown in the terminal.

### Option B: Open the HTML file (UI-only)

1.  Clone or download the repository.
2.  Open `index.html` in your preferred web browser.
3.  Browse matches and watch prices change in real-time.
