# Task: Create High-Demand Sport Ticket App (AlphaGrab.app)

## Overview

Created a modern, responsive web application for browsing high-demand sports
tickets across UK, Europe, and World regions. The app features a premium
glassmorphism design, mock data with live-simulated pricing, and region-based
filtering.

## Files Created

- `index.html`: Main application structure, including hero section and matches
  grid.
- `style.css`: Custom styling with dark mode, glassmorphism effects, and
  responsive layout.
- `app.js`: Logic for rendering matches, filtering, sorting, and simulating live
  price updates.

## Features

- **Featured Match**: Highlights a top-tier game in the hero section.
- **Filtering**: Filter by 'UK & England', 'Europe', or 'World'.
- **Sorting**: Sort by Price, Date, or Popularity.
- **Simulated Live Prices**: Prices update randomly every 5 seconds to simulate
  a live market.
- **Responsive Design**: Works on desktop and mobile.

## Technology Stack

- Vanilla HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Font Awesome (Icons)
- Google Fonts (Outfit)
